# Симулятор живого человека — переговорный тренажёр

Тренажёр жёстких переговоров с 3D-аватаром оппонента, который **скрывает
эмоции не хуже реального человека** — а игрок должен научиться их считывать.

## Живой прототип

- **Сайт:** https://frontend-ten-bice-48.vercel.app
- **API бэкенда:** https://hackathon-negotiator-backend.onrender.com

Открывается сразу, без установки и без входа — пройти сценарий как гость
можно с главного экрана. Бэкенд на бесплатном тарифе Render «засыпает» при
простое — первый запрос после паузы может занять до ~50 секунд.

## Проблема

Курсы переговоров учат фразам и тактикам, но не главному навыку —
распознаванию несоответствия между словами оппонента и его реальным
эмоциональным состоянием. Живого тренера с актёрским мастерством для
отработки этого навыка не наймёшь на каждую сессию.

## Решение

9 оппонентов с разными переговорными архитипами (Жёсткий Торгаш,
Молчун-Стратег, Паникёр-Драматург, Ледяная Прагматик и др.), каждый со
своими скрытыми интересами и BATNA, которые не раскрываются напрямую —
их нужно вычислить по ходу диалога.

**Ключевая механика — «Пауза Лайтмана».** Каждая реплика оппонента
генерируется в два прохода:
1. DeepSeek пишет реплику от лица персонажа.
2. Claude проверяет её на соответствие характеру и скрытым интересам,
   решает, блефует ли персонаж, и генерирует эмоциональный тег в
   формате FACS (Facial Action Coding System) — те же коды, которыми
   пользуются профайлеры и тренеры по методике Пола Экмана.

FACS-код превращается в веса 52 ARKit blend shapes и анимирует
3D-голову оппонента (Three.js) в реальном времени. Если персонаж
говорит «меня всё устраивает», но лицо на долю секунды выдаёт
презрение — это и есть момент, который должен поймать игрок.

**Карточка результата.** После завершения сессии Claude разбирает всю
стенограмму переговоров относительно реальных (не раскрытых игроку)
скрытых интересов и BATNA персонажа и выставляет оценку по 6 осям:
цель достигнута, защита BATNA, дисциплина по информации, раппорт,
разнообразие тактик, эмоциональная выдержка. Результат — SVG
радар-чарт без сторонних зависимостей. При сбое ИИ-оценки есть
детерминированный fallback, чтобы демо не падало.

**Конфигурируемость под контекст.** Администратор на экране выбора
персонажа может задать сферу и тему переговоров, сложность, тон
собеседника, его роль и цели — это вплетается в системный промпт
персонажа текстовым блоком, не переопределяя его характер, скрытые
интересы или BATNA. Один и тот же тренажёр подстраивается под разные
учебные задачи и аудитории.

**Аккаунты компаний (опционально).** При подключённом Supabase-проекте
на сайте появляется вход/регистрация для компаний: сотрудник входит
под учёткой компании, а на отдельном экране видна история всех
пройденных сессий сотрудников этой компании (доступ разграничен на
уровне базы данных — компания видит только своих). Без переменных
`VITE_SUPABASE_URL`/`VITE_SUPABASE_ANON_KEY` экран входа не
появляется вообще, и всё работает как обычная анонимная демо-сессия —
это осознанное решение, чтобы жюри могло пройти сценарий без
регистрации.

**Видео-лицо оппонента (опционально, в разработке).** Помимо 3D-рига
с блендшейпами, есть готовый компонент для замены лица на
предзаписанные видео-ролики (например, из HeyGen) — библиотека из 8
роликов: нейтральный фон + по одной короткой вспышке на каждую из 7
базовых эмоций Экмана. Переключается переменной `VITE_AVATAR_MODE`.
Подсветка зоны утечки («Пауза Лайтмана») не зависит от того, какой
режим лица выбран.

## Технологии

- **Backend:** FastAPI, DeepSeek (генерация реплик), Claude (валидация
  характера + эмоциональный тег + итоговый разбор), WebSocket для
  диалога в реальном времени, опционально Supabase (аккаунты
  компаний, персистентность истории сессий).
- **Frontend:** React + Vite, Three.js (`facecap.glb`, 52 ARKit blend
  shapes) для 3D-аватара с микромимикой, опционально
  `@supabase/supabase-js` (вход/регистрация) и видео-аватар вместо
  3D-рига.
- **Деплой:** Render (бэкенд) + Vercel (фронтенд) — см. `DEPLOY.md`
  для пошаговой инструкции разворачивания собственной копии, включая
  настройку Supabase и подключение видео-роликов.

## Как запустить локально

```bash
# Backend
cd backend
python3.11 -m venv .venv && source .venv/bin/activate
pip install -r ../requirements.txt
cp ../.env.example .env   # вписать DEEPSEEK_API_KEY и ANTHROPIC_API_KEY
                          # (SUPABASE_* — не обязательны для локального запуска)
uvicorn server:app --reload

# Frontend (в отдельном терминале)
cd frontend
npm install
npm run dev
```

Фронтенд по умолчанию открывается на `http://localhost:5173`, бэкенд
слушает `http://localhost:8000`.
