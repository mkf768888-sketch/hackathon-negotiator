# Симулятор живого человека — переговорный тренажёр

Тренажёр жёстких переговоров с 3D-аватаром оппонента, который **скрывает
эмоции не хуже реального человека** — а игрок должен научиться их считывать.

## Проблема

Курсы переговоров учат фразам и тактикам, но не главному навыку —
распознаванию несоответствия между словами оппонента и его реальным
эмоциональным состоянием. Живого тренера с актёрским мастерством для
отработки этого навыка не наймёшь на каждую сессию.

## Решение

9 оппонентов с разными переговорными архитипами (Жёсткий Торгаш,
Молчун-Стратег, Паникёр-Драматург, Ледяная Прагматик и др.), каждый со
своими скрытыми интересами и BATNA, которые не раскрываются напрямую —
их нужно вычислить по ходу диалога.

**Ключевая механика — «Пауза Лайтмана».** Каждая реплика оппонента
генерируется в два прохода:
1. DeepSeek пишет реплику от лица персонажа.
2. Claude проверяет её на соответствие характеру и скрытым интересам,
   решает, блефует ли персонаж, и генерирует эмоциональный тег в
   формате FACS (Facial Action Coding System) — те же коды, которыми
   пользуются профайлеры и тренеры по методике Пола Экмана.

FACS-код превращается в веса 52 ARKit blend shapes и анимирует
3D-голову оппонента (Three.js) в реальном времени. Если персонаж
говорит «меня всё устраивает», но лицо на долю секунды выдаёт
презрение — это и есть момент, который должен поймать игрок.

**Карточка результата.** После завершения сессии Claude разбирает всю
стенограмму переговоров относительно реальных (не раскрытых игроку)
скрытых интересов и BATNA персонажа и выставляет оценку по 6 осям:
цель достигнута, защита BATNA, дисциплина по информации, раппорт,
разнообразие тактик, эмоциональная выдержка. Результат — SVG
радар-чарт без сторонних зависимостей. При сбое ИИ-оценки есть
детерминированный fallback, чтобы демо не падало.

## Технологии

- **Backend:** FastAPI, DeepSeek (генерация реплик), Claude (валидация
  характера + эмоциональный тег + итоговый разбор), WebSocket для
  диалога в реальном времени.
- **Frontend:** React + Vite, Three.js (`facecap.glb`, 52 ARKit blend
  shapes) для 3D-аватара с микромимикой.

## Как запустить локально

```bash
# Backend
cd backend
python3.11 -m venv .venv && source .venv/bin/activate
pip install -r ../requirements.txt
cp ../.env.example .env   # вписать DEEPSEEK_API_KEY и ANTHROPIC_API_KEY
uvicorn server:app --reload

# Frontend (в отдельном терминале)
cd frontend
npm install
npm run dev
```

Фронтенд по умолчанию открывается на `http://localhost:5173`, бэкенд
слушает `http://localhost:8000`.
