## 1. Техническая архитектура

### Backend
- **FastAPI** — REST + WebSocket для стриминга реплик оппонента
- **LangChain** — оркестрация диалога, хранение памяти персонажа (характер, BATNA, скрытые интересы, история 20+ реплик)
- **LLM-роутер** (адаптация уже существующего `llm_router.py` из `babylon_bot/`):
  - **DeepSeek V3** — генерирует основной текст реплики оппонента (дёшево, быстро, держит роль)
  - **Claude** — второй проход: проверяет реплику на соответствие характеру/скрытым интересам, генерирует эмоциональный тег в формате FACS (см. `PROMPTS.md`), решает — блефует оппонент или нет
  - Итоговый ответ фронту: `{ "text": "...", "emotion": {...FACS-теги...}, "batna_shift": -0.05, "trigger": null }`

### Frontend
- **React** + **Three.js** (рендер 3D-головы) + **Framer Motion** (UI-анимации дашборда)
- **3D-аватар**: берём готовую rigged 3D-голову с ARKit-совместимыми blendshapes (52 стандартных морф-таргета — этого достаточно, чтобы покрыть 7 базовых эмоций Экмана + их комбинации/микровыражения). Не рисуем риг с нуля — это нереально за 7 дней. Загружаем через `GLTFLoader`, крутим `morphTargetInfluences` по таблице маппинга FACS Action Units → веса блендшейпов.
- **Механика «Пауза Лайтмана»**: пробел останавливает поток, замедление через таймлайн Three.js/React Spring, подсветка «горячих точек» лица (брови/губы/глаза) через оверлей-слой поверх canvas.
- **Дашборд**: шкала BATNA, «зона компромисса», цветовая аура (CSS-градиент по emotion-тегу)
- **Web Speech API** — голосовой ввод/вывод (по возможности, не блокирует MVP)

### Хостинг и деплой
1. Railway: оплатить план (Upgrade), передеплоить `worker` сервис (backend уже настроен — Procfile/railway.toml на месте)
2. Vercel: подключить фронтенд-репо, авто-деплой при пуше в main
3. Переменные окружения: `BOT_TOKEN` (если нужен Telegram-канал демо), `DEEPSEEK_API_KEY`, `ANTHROPIC_API_KEY`
